# alrc-align

音源と歌詞から、ぴったり同期する歌詞ファイル（`.alrc`）を自動で作るツールです。
[Think Songs](https://think-songs.com) の開発者向けのお試し版で、Mac（Apple シリコン）と 64 ビットの Windows で動きます。

- 行ごと・文字ごとの時刻を自動で付けます
- 漢字にふりがなを付け、歌声と合わない読みは確かめます
- 音源も歌詞も外へ送らず、パソコンの中だけで処理します
- 歌声を分離するモデルも時刻を付けるモデルもパソコンの中で動くので、すべて無料で使えます
- ご自分の契約しているAPIキー(Gemini or OpenAI or Claude) を入れると、背景画像も作ります

歌詞は自分で用意してください（歌詞サイトから自動では取りません）。

## 料金

料金がかかるのは、1200×1200 の背景画像を作るときだけです。料金は各サービスから直接請求されます。

| サービス | モデル | 1 枚の目安 |
|---|---|---|
| Gemini | `gemini-nano-banana-2.1` | 約 10 円（$0.062） |
| OpenAI | `gpt-image-2.5-sunburst` | 約 9 円（$0.055） |
| Claude | `claude-opus-5-5` | 53 円以内（$0.33 以内） |

1 ドル 160 円で計算した、2026 年 11 月時点の目安です。Claude は描く図形の量で変わるので、上限を載せています。

## 入手と使い方

**<https://think-songs.com/alrc-align>** からダウンロードできます。Python や ffmpeg を入れる必要はありません。
